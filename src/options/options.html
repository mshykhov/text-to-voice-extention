About

How to Use

  1. Enter your OpenAI API key above and save it
  2. Navigate to any webpage with text content
  3. Click the extension icon in your browser toolbar
  4. Click "Read Page" to start listening
  5. Use playback controls to pause, resume, or stop

Voice Options

Choose from 6 different voices in the popup:

  • Alloy - Neutral voice
  • Echo - Male voice
  • Fable - British male voice
  • Onyx - Deep male voice
  • Nova - Female voice
  • Shimmer - Soft female voice

Pricing

OpenAI TTS API pricing is very affordable:

  • Standard: $0.015 per 1,000 characters
  • HD: $0.030 per 1,000 characters

For example, reading a 10,000 character article costs only $0.15 (standard) or $0.30 (HD).

Privacy

Your API key is stored locally in your browser using Chrome's sync storage. The extension only communicates with OpenAI's API - no third parties are involved.
