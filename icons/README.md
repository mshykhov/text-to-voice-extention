# Icons

SVG icons are provided. Convert to PNG using any tool:

## Quick conversion (ImageMagick):
```bash
convert icon16.svg icon16.png
convert icon48.svg icon48.png
convert icon128.svg icon128.png
```

## Online conversion:
- Use https://cloudconvert.com/svg-to-png
- Or any SVG to PNG converter

PNG icons must be created before loading the extension.
